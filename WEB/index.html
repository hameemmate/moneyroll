About the App

Moneyroll is a comprehensive expense management solution designed for individuals, employees, and HR professionals. Manage your expenses efficiently without any login requirements, using only local storage for complete privacy.

Key Features

For Everyone

No login required. Use it as individual, employee, or HR professional.

Expense History

View and edit your complete expense history with powerful filtering.

Import & Export

Export your data before deleting the app. Import it back anytime.

Local Storage

All data stored locally on your device. No cloud, no API, complete privacy.

Full Edit Control

Edit any expense entry anytime. No restrictions.

Important Data Safety Note

Warning: Local Storage Only

Moneyroll uses only local mobile database (no cloud backup). Always export your data before:

  • Uninstalling the app
  • Resetting your device
  • Clearing app data/cache

Technical Information

Storage Method

Local mobile database

Data Privacy

100% local - no data leaves your device

Backup Method

Manual export/import via file system

How to Export Your Data

To safely export your expense data:

1. Go to History screen

Navigate to the expense history section

2. Tap "Export" button

Find and press the export button

3. Choose export location

Select where to save your backup file

4. Save the .json file

Confirm to save your data as JSON file

5. Keep the file safe

Store the backup file in a secure location

Import the same file anytime to restore all your data.
